# Migrating to v0.49.0

golib removes `otel/utils`, whose response writer logged the last status a handler set instead of the
one it sent. The HTTP logging presets now capture each response through
[httpsnoop](https://github.com/felixge/httpsnoop).

## Do I need to act?

**No, in every service.** No service imports `otel/utils`, and the presets keep their configuration and
log fields. Only code that wraps a writer in `utils.CaptureHTTPResponseWriter` stops compiling.

## Capture responses with httpsnoop

`utils.CaptureHTTPResponseWriter` and `utils.ErrNotHijackable` are removed. Use
`github.com/felixge/httpsnoop` directly. golib already depends on it, so the module adds nothing to the
build, and `go mod tidy` lists it as a direct requirement.

```go
// before
wrapped := &utils.CaptureHTTPResponseWriter{ResponseWriter: w}
next.ServeHTTP(wrapped, r)
status, size := wrapped.Status(), wrapped.Size()

// after
metrics := httpsnoop.CaptureMetrics(next, w, r)
status, size := metrics.Code, metrics.Written
```

`metrics.Code` is the status net/http sent: the first final status, after any informational one. The
writer the handler receives implements exactly the optional interfaces of `w`. A handler that asserts
`http.Hijacker` on an HTTP/2 writer gets `false`, where `Hijack` used to return `ErrNotHijackable`.

`Response()` returned the body of a failed response. To keep a body, wrap `w` with a Write hook before
capturing, and bound what the hook keeps:

```go
var body []byte

keepBody := httpsnoop.Hooks{
	Write: func(write httpsnoop.WriteFunc) httpsnoop.WriteFunc {
		return func(b []byte) (int, error) {
			n, err := write(b)
			body = append(body, b[:min(n, limit-len(body))]...)

			return n, err
		}
	},
}

metrics := httpsnoop.CaptureMetrics(next, httpsnoop.Wrap(w, keepBody), r)
```

## What the presets log

`loggingpresets.HTTPGcloud` and `loggingpresets.HTTPLocal` log the same fields. Two values change:

- A handler that calls `WriteHeader` twice, or after writing, is logged with the status the client
  received.
- `HTTPLocal` prints at most 4 KiB of a failed response body. The client still receives the whole body.
