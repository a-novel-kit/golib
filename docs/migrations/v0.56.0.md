# Migrating to v0.56.0

golib removes `otelpresets.Gcloud`, `loggingpresets.LogGcloud`, `loggingpresets.HTTPGcloud` and
`loggingpresets.GRPCGcloud`, which v0.54.0 deprecated. The gRPC OTLP exporters and the Google Cloud
resource detector leave golib's dependencies with them.

## Do I need to act?

**No, in every service.** Each one exports through `otelpresets.OTLP` and logs through
`loggingpresets.LogOTel`. Code that still names a removed preset stops compiling: switch it as
[the v0.54.0 guide](./v0.54.0.md) shows before bumping golib.

Run `go mod tidy` after the bump. It drops the modules golib no longer requires, such as
`go.opentelemetry.io/otel/exporters/otlp/otlptrace/otlptracegrpc`, unless the service imports them.
