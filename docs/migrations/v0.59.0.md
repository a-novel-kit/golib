# Migrating to v0.59.0

`httpf.ServiceTokenMiddleware` tells handlers which service called (a-novel/.github#549).
`httpf.ServiceTokenCaller` returns the caller whose service token the middleware verified, such as
`system:serviceaccount:studio:web`. To give it that caller, `servicetoken.Verifier.Verify` returns
the caller with its error.

## Do I need to act?

**No, in every service.** No service calls `Verify` directly: the httpf and grpcf glue does. Code
that calls it stops compiling.

## Take the caller from `Verify`

```go
// before
err := verifier.Verify(ctx, token)

// after
caller, err := verifier.Verify(ctx, token)
```

Discard the caller with `_` where the call only checks the token.
