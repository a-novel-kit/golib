# Migrating to v0.50.0

golib removes `otel.ReportSuccess` and `otel.ReportSuccessNoContent`, which v0.47.0 deprecated. Both
recorded nothing on the span.

## Do I need to act?

**No, in every service.** No service calls either function. Code that still calls them stops compiling.

## Return values instead of calling `otel.ReportSuccess`

A successful operation leaves its span status unset, so return the value directly and drop the call:

```go
// before
return otel.ReportSuccess(span, &project), nil

otel.ReportSuccessNoContent(span)

// after
return &project, nil
```

Rewrite the calls from the module root, then delete each `otel.ReportSuccessNoContent(span)` line:

```bash
gofmt -r 'otel.ReportSuccess(a, b) -> b' -w .
```

A call that names its type argument, such as `otel.ReportSuccess[T](span, value)`, needs the same edit by
hand.
