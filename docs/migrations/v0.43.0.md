# Migrating to v0.43.0

`httpf.Limits.By` takes the `httpf.Rate` a service reads from its environment, instead of a count
and a window.

## Do I need to act?

**Only if you call `Limits.By`.** It shipped in v0.42.0; a call to it stops compiling.

## Pass a rate to By

```go
// before
limits.By(rate.Requests, rate.Window, key)

// after
limits.By(rate, key)
```

Read the rate from the environment like any setting, writing its default the way the variable does:

```go
var RateDefault = config.Must(httpf.ParseRate("3/5m"))

Rate = config.LoadEnv(getEnv("REST_RATE_LIMIT_STRICT"), RateDefault, httpf.ParseRate)
```
