# Migrating to v0.44.0

A service's `main` builds and runs each server in one line, like the rest of its wiring.

## Do I need to act?

**Yes, if you call `httpf.NewRouter`, `Limits.Standard` or `grpcf.NewServer`.** They stop compiling.

## Build the REST router in one line

`NewRouter` takes its dependencies directly, and applies the standard rate limit itself, so routes
mount on the router without a group. The ping path and the CORS methods moved into `ServerConfig`:
`REST_LIVENESS_PATH` (default `/ping`) and `REST_CORS_ALLOWED_METHODS` (every common method).

```go
// before
router := httpf.NewRouter(cfg.Rest, httpf.RouterOptions{
	Otel:          cfg.Otel,
	Logger:        cfg.HttpLogger,
	DowntimeStart: cfg.App.DowntimeStart,
	Liveness:      "/ping",
	Methods:       []string{http.MethodGet, http.MethodPost},
})
router.Get("/ping", handlerPing.ServeHTTP)
router.Group(func(api chi.Router) {
	api.Use(httpf.NewLimits(cfg.Rest).Standard())
	api.Get("/items", handlerItemList.ServeHTTP)
})

err := httpf.Serve(ctx, httpf.NewServer(ctx, cfg.Rest, router), cfg.Rest.Timeouts.Shutdown)

// after
router := httpf.NewRouter(cfg.Rest, cfg.Otel, cfg.HttpLogger, cfg.App.DowntimeStart)
router.Get("/ping", handlerPing.ServeHTTP)
router.Get("/items", handlerItemList.ServeHTTP)

err := httpf.ListenAndServe(ctx, cfg.Rest, router)
```

A service whose ping path is not `/ping` sets `Liveness` on its defaults, as it sets any other
default.

## Build the gRPC server in one line

```go
// before
server := grpcf.NewServer(grpcf.ServerOptions{
	Otel:          cfg.Otel,
	Logger:        cfg.Logger,
	DowntimeStart: cfg.App.DowntimeStart,
	BaseContext:   ctxInterceptor,
})

err := grpcf.Serve(ctx, server, fmt.Sprintf("0.0.0.0:%d", cfg.Grpc.Port), cfg.Grpc.Shutdown)

// after
server := grpcf.NewServer(cfg.Otel, cfg.Logger, cfg.App.DowntimeStart, ctxInterceptor)

err := grpcf.ListenAndServe(ctx, cfg.Grpc, server)
```
