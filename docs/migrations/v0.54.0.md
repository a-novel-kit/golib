# Migrating to v0.54.0

golib exports traces and logs over OTLP/HTTP to any backend that the standard OpenTelemetry
variables name, and deprecates its Google Cloud presets.

## Do I need to act?

**Not to build.** Every existing preset keeps working. Lint now flags each use of
`otelpresets.Gcloud`, `loggingpresets.LogGcloud`, `loggingpresets.HTTPGcloud` and
`loggingpresets.GRPCGcloud`, which a later release removes. Switch each service as below.

## Export over OTLP/HTTP

`otelpresets.OTLP` replaces `otelpresets.Gcloud`. The preset sets no exporter option of its own.
The deployment names the backend through the standard variables:

| Variable                         | Holds                                                           |
| -------------------------------- | --------------------------------------------------------------- |
| `OTEL_EXPORTER_OTLP_ENDPOINT`    | The base URL. The exporters append `/v1/traces` and `/v1/logs`. |
| `OTEL_EXPORTER_OTLP_HEADERS`     | The headers each export sends, such as an authentication key.   |
| `OTEL_EXPORTER_OTLP_COMPRESSION` | `gzip`, to compress each export.                                |
| `OTEL_SERVICE_NAME`              | The service name every span and log record carries.             |

`UntracedPaths` lists the request paths that produce no span, such as a liveness probe's. A
handler under such a path still opens its span, and the preset drops it.

```go
// before
Otel: &otelpresets.Gcloud{ProjectID: projectID, FlushTimeout: otelFlushTimeout},

// after
Otel: &otelpresets.OTLP{UntracedPaths: []string{"/v2/ping"}, FlushTimeout: otelFlushTimeout},
```

Pick the preset from the endpoint, so a deployment without one keeps the local presets:

```go
switch {
case !env.Otel:
	return &otelpresets.Disabled{}
case os.Getenv("OTEL_EXPORTER_OTLP_ENDPOINT") != "":
	return &otelpresets.OTLP{UntracedPaths: []string{"/v2/ping"}, FlushTimeout: otelFlushTimeout}
default:
	return &otelpresets.Local{FlushTimeout: otelFlushTimeout}
}
```

Set the variables only once the image that reads them is deployed. `otelpresets.Gcloud` reads
`OTEL_EXPORTER_OTLP_HEADERS` too, and sends those headers to Google's Telemetry API.

## Log through OpenTelemetry

`loggingpresets.LogOTel` replaces `loggingpresets.LogGcloud`. It writes through the global
OpenTelemetry logger provider, so application logs reach the same backend, linked to the span they
were logged under.

```go
// before
Logger: &loggingpresets.LogGcloud{ProjectID: projectID},

// after
Logger: &loggingpresets.LogOTel{},
```

`loggingpresets.GRPCOTel` replaces `loggingpresets.GRPCGcloud`. Each call's RPC span is its record,
so the preset logs no call. Its recovery still turns a handler panic into an internal error.

`httpf.NewRouter` takes a nil logger, which writes no request log. Pass it in place of
`loggingpresets.HTTPGcloud`: the server span is each request's record.

```go
// before
router := httpf.NewRouter(cfg.Rest, cfg.Otel, &loggingpresets.HTTPGcloud{BaseLogger: logger}, downtimeStart)

// after
router := httpf.NewRouter(cfg.Rest, cfg.Otel, nil, downtimeStart)
```
